# HRV 验证版 Implementation Plan

**Goal:** 交付可云端编译、供 Windows 侧载的最小原生 HRV 工程。
**Architecture:** SwiftUI 界面，主线程状态模型，HealthKit 异步只读查询。
**Tech Stack:** Swift 5、SwiftUI、Charts、HealthKit、XcodeGen、GitHub Actions。
**Spec:** ../specs/2026-10-31-hrv-design.md

## Global Constraints
零开发者会员费用，无上传健康数据；真机能力尚待验证。

## Review Focus
拒绝读取与无样本不可区分；样本单位应为毫秒；异步状态更新应在主线程；重复点击不并发请求；签名必须保留 HealthKit entitlement。
